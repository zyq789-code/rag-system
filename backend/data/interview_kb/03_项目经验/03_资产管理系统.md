## 项目：企业级资产管理系统

### 简介
面向企业内部的资产全生命周期管理系统：资产台账、领用/归还/调拨、盘点、审批流程、报表统计。

### 技术栈
Spring Boot 2.7 + MyBatis-Plus + MySQL + Redis ｜ Vue 3 + Element Plus ｜ Maven 多模块 ｜ Docker Compose 部署

### 我的职责与设计
- 后端：多模块工程（common / system / business），统一响应封装、全局异常处理、参数校验
- 资产全生命周期：领用、归还、调拨、维修、报废等状态流转，状态机管理保证流转合法
- 审批流：基于角色/部门的审批链，Redis 缓存权限与用户信息减少 DB 压力
- 列表查询：分页 + 多条件组合查询，复杂查询走 MyBatis-Plus 条件构造器 + 索引优化
- 前端：Vue3 + Element Plus 管理后台，路由权限控制

### 遇到的典型问题
- 大表资产列表查询慢 → 加联合索引 + 覆盖索引优化
- 并发领用同一资产 → 乐观锁（version）或行锁保证不超领
- 审批流程状态一致性 → 状态机 + 幂等校验
