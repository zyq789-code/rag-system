## 项目：微服务电商后台（含秒杀）

### 简介
基于微服务架构的电商后台，包含秒杀、订单、商品、用户等模块；秒杀场景是高并发压测的核心。

### 技术栈
Spring Boot 3.5 + JDK 17 ｜ Spring Cloud 网关（Gateway） ｜ RocketMQ + Redis + MySQL ｜ Nacos 注册中心 ｜ 多服务拆分

### 秒杀的核心设计
- **前端/网关限流**：拦截大部分请求，令牌桶限流 + 验证码/按钮置灰
- **Redis 预扣库存**：库存预热到 Redis，`DECR` 原子扣减，减少 DB 冲击
- **MQ 削峰**：下单请求入 RocketMQ 队列异步处理，消费者批量落库
- **接口幂等**：防重复下单，基于 userId+skuId 去重
- **本地消息表/事务消息**：保证"扣库存 + 创建订单"的最终一致性

### 我的职责
- 秒杀接口与库存一致性：Redis 预扣 + MQ 异步 + 状态机补偿
- 网关统一鉴权与限流
- 数据库表设计与索引优化
- 压测验证：用 JMeter 压测接口，定位热点与瓶颈

### 典型问题
- 超卖：通过 Redis 原子扣减 + DB 乐观锁双重保证
- 库存数据一致性：Redis 与 DB 最终一致，定时对账
- 热点 key：库存 key 单点热点，分片 + 本地缓存缓解
